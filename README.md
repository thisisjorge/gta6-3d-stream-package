# GTA 6 Stream Package 3D — `@apenasojorge` (Miami Sunset + WebGL 3D)

Pacote **100% unificado** de overlays 3D interativos para **OBS Studio / Streamlabs** criado para o canal **`@apenasojorge`** (*Twitch, YouTube, Kick & TikTok `@livesjorge`*).

## Estúdio de Preview & Controle
Abra [**`index.html`**](index.html) (ou [**`preview.html`**](preview.html)) para testar todas as cenas, molduras de câmera (`Cam 1` a `Cam 4`), barra de meta (`Meta Seguidores` / `Meta Subs`), transição Stinger e os **10 alertas com efeitos sonoros exclusivos e props 3D**.

## Cenas Incluídas (`1920x1080 @ 60 FPS`)
- **`overlay-gameplay.html`** — HUD de Gameplay limpa (moldura 16:9 `Cam 3` Jacaré + Sol por padrão, trocável via `?frame=cam1|cam2|cam3|cam4|sunset`, só a Pistola 3D na quina, barra `@apenasojorge` YT/Twitch/Kick e barra de Meta Seguidores/Subs opcional).
- **`cena-inicio.html`** — Logo Oficial do GTA 6 Animada + 6 Estrelas + Cronômetro Regressivo + Algemas 3D, Pistola 3D e Maço de US$ 100 3D.
- **`cena-chat.html`** — Tela Só Chat com janela vazada 1280x720 para sua webcam, área de Chat ao Vivo e objetos 3D.
- **`cena-pausa.html`** — Tela de Pausa (*Já Volto*) com equalizador animado e objetos 3D.
- **`cena-fim.html`** — Tela de Encerramento (*Missão Concluída*) com cards da Twitch, YouTube, Kick e TikTok (`@livesjorge`).
- **`cena-missao.html`** — Animação em tela cheia transparente *Missão Concluída 3D*.
- **`transicao.html`** — Transição Stinger diagonal Miami Sunset com a Logo Animada do GTA 6 e `@apenasojorge`.
- **`chat-widget.html`** — Widget de Chat conectado em tempo real via WebSocket oficial da Twitch (`#apenasojorge`).
- **`preview-alertas.html` / `streamelements-alert.*` / `livepix-alert.css`** — Alertas em tempo real (Follow, Sub, Gift Sub, Bits, Donate em 4 tiers evolutivos, Raid Polícia 6★ e LivePix) com trilhas sonoras exclusivas Web Audio API e modelos 3D giratórios.
